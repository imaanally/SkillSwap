# SkillSwap

## Project Overview

SkillSwap is a web application that allows users to exchange skills with one another. Users can discover skills, connect with other learners and arrange skill-sharing sessions.

## Technology Stack

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Python
- Flask
- REST API
- JSON

### Database

- PostgreSQL

### Version Control

- Git
- GitHub

## Getting Started

### Prerequisites

- Node.js and npm
- Python 3
- PostgreSQL
- Git

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

Backend installation and configuration instructions will be added as the Flask environment is established.
